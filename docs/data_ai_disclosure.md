# Data and AI disclosure statement

## Data provenance
The project uses publicly citable frozen files: Epoch AI's Notable AI Models and Epoch Capabilities Index (ECI), and CSET AI publication data redistributed through Our World in Data. Group snapshot: **20 October 2026**. The raw inputs remain unchanged and their SHA-256 fingerprints are in docs/source_checksums.sha256. Original source links, use restrictions and licences appear in docs/data_sources_and_licenses.md. The CSET component carries **CC BY-NC 4.0** restrictions.

## Processing and interpretation
The group filters country–model records, retains multinational contributions in both affected countries, classifies model-level organisation types, groups related organisation labels, and distinguishes release access categories. Charts 3–5 use archived *student-reviewed classification inputs* in data/review; these decisions are not misrepresented as automatically inferred facts. Rebuild and verification commands are documented in README.md and docs/REPRODUCIBILITY.md.

## AI assistance
ChatGPT and Claude were used for substantive software and writing assistance, including Streamlit/Plotly code scaffolding, HTML chart integration, debugging, data-validation scripts, narrative wording and literature-context drafting. Such output is not assumed accurate simply because it was generated by an AI system. The confirmed use records in docs/ai_provenance_matrix.csv identify the artefacts, person, prompts, outputs, failure-capable verification checks and outcomes.

## Verification and limits
The project checks the original CSV, review-input membership, shared counting denominators, ECI exact-name matching and reconstructibility of derived tables. Uncertainty is stated when the source population is selected rather than exhaustive, and model capabilities are not inferred solely from training compute, model counts or one benchmark score.
